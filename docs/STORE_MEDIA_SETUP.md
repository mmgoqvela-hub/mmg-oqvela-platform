# Store image storage (Cloudflare R2)

The store designer uploads logos and hero images to the Worker's R2 binding named `STORE_MEDIA`.

## One-time Cloudflare setup

1. Open the Cloudflare dashboard and select the account that owns the `mmg-oqvela-platform` Worker.
2. Open **R2 Object Storage** and create a bucket named exactly `mmg-oqvela-store-media`.
3. The repository's `wrangler.toml` already declares the binding:

   ```toml
   [[r2_buckets]]
   binding = "STORE_MEDIA"
   bucket_name = "mmg-oqvela-store-media"
   ```

4. Deploy the Worker after the bucket exists. No public R2 bucket URL or public bucket access is required; images are delivered through the Worker's `/media/<store-id>/<random-file>.<extension>` route.

## CLI alternative

From the repository root, after authenticating Wrangler with the correct Cloudflare account:

```sh
npx wrangler r2 bucket create mmg-oqvela-store-media
npx wrangler deploy
```

If the bucket already exists, do not create it again; simply deploy the updated Worker.

## Upload policy

- Maximum file size: 5 MiB.
- Allowed formats: JPEG, PNG, WebP and GIF. SVG is intentionally not accepted.
- Uploads require a valid platform session and owner/admin access to the selected store.
- The Worker checks the file signature and caps the multipart request body before parsing it.
- Object keys are generated by the server and namespaced by store ID.
- Uploaded images are public storefront assets served through the Worker with `nosniff` and a restrictive content security policy.

## Verification

After deployment, sign in as a store owner, open **Manage store → Store design**, select a logo or hero image from the device and upload it. The uploaded URL is inserted into the editor; press **Save store details** to publish the appearance settings.
