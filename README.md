# MMG OQVELA Platform

A multi-tenant SaaS platform developed by MMG OQVELA.

## Project Structure

- frontend/: Platform and store interfaces
- backend/: API and application logic
- database/: Database schema and migrations
- modules/: Independent platform modules
- templates/: Store templates
- assets/: Images, icons and styles
- config/: Application configuration
- tests/: Automated tests
- docs/: Project documentation

## Technology Stack

- HTML
- CSS
- JavaScript
- Cloudflare Workers
- Cloudflare D1
- Cloudflare R2
- Git and GitHub

## Development

Install dependencies:

npm install

Start development server:

npm run dev

## Deployment

npm run deploy

## Security

Sensitive credentials must never be committed to GitHub.
